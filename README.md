# Useful script collection

This is a collection of scripts for my personal workflow.

## Design Decisions

### Core Tools

- [fzf](https://github.com/junegunn/fzf) as a picker
- [ripgrep](https://github.com/burntsushi/ripgrep) for searching
- [sioyek](https://github.com/ahrm/sioyek) for opening pdfs
- [neovim](https://github.com/neovim/neovim) as an editor
